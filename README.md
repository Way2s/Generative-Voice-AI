# Generative-Voice-AI

Deep learning models for real-time, emotive text-to-speech synthesis.

## Project Structure
- `backend-go/server.go` — Primary Go service module
- `src/` — Supporting runtime configuration, retry, and cache utilities
- `tests/` — Unit tests and boundary checks
- `docs/` — Architecture and operational notes
